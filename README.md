# Классификация обращений в поддержку интернет-магазина

Система автоматически определяет тему обращения покупателя и направляет его в нужную очередь поддержки.

---

## О проекте

Интернет-магазин получает сотни обращений в поддержку ежедневно. Операторы вручную сортируют их по темам — это занимает время, приводит к ошибкам и задержкам в ответе.

**Цель проекта** — автоматически определять категорию обращения и направлять его в нужную очередь, чтобы:
- сократить время первого ответа клиенту,
- снизить нагрузку на операторов,
- уменьшить количество ошибок при маршрутизации.

**Пользователи:**
- **Основной:** оператор поддержки интернет-магазина.
- **Косвенный:** покупатель, который быстрее получает ответ.

---

## Датасет

Используется датасет с Kaggle:
[Training Dataset for Chatbots/Virtual Assistants](https://www.kaggle.com/datasets/bitext/training-dataset-for-chatbotsvirtual-assistants)

**Входные данные:** текст обращения покупателя, отправленный через форму на сайте или в чате поддержки.

---

## 🏗️ Архитектура

```text
Покупатель (форма на сайте)
   │ отправляет обращение
   ▼
Приложение интернет-магазина
   │ POST /v1/classify { text }
   ▼
API-сервис классификации (FastAPI)
   │
   ▼
Модель классификации
   │
   ▼
Хранилище истории решений (для мониторинга)
```

**Логика работы:**
1. Покупатель отправляет текст обращения.
2. Приложение магазина передаёт текст в API-сервис классификации.
3. Модель определяет категорию и уверенность.
4. На основе категории обращение попадает в нужную очередь.

**Обоснование обработки:**
**Обработка — stream:** обращение должно классифицироваться сразу при поступлении, задержка критична для пользовательского опыта. Модель развёрнута как отдельный сервис (**model-as-a-service**), чтобы её можно было обновлять независимо от приложения магазина.

## API-контракт

**POST** `/v1/classify`

### Вход

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `text` | string | да | Текст обращения покупателя |

### Пример запроса

```json
{
  "text": "не приходят деньги за заказ"
}
```

### Пример успешного ответа

```json
{
  "category": "оплата",
  "confidence": 0.87,
  "queue": "billing_support",
  "model_version": "2026-09-21"
}
```

### Коды ошибок

| Код | Причина | Тело ответа |
|-----|---------|-------------|
| `422` | Пустой `text` или текст длиннее 5000 символов | `{ "detail": "text is required" }` |
| `503` | Модель не загружена | `{ "detail": "model not loaded" }` |
